# Heathland vegetation data

A dataset containing the cover and sub-turf presences of plants in two
turfs on Norwegian coastal heathland recorded over four years.

## Format

A tibble with 198 rows and 21 variables:

- site:

  Site code

- year:

  year of sampling

- species:

  Species

- cover:

  Percent cover

- freq1:

  Presence/absence in subturf 1
